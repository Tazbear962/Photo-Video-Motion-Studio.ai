# Photo Video Motion Studio.ai

A comprehensive AI-powered media creation and editing platform.

## 🚀 Features

### Core Capabilities
- **Image & Video Generation** - AI-powered text-to-image and video-to-video generation
- **Media Display** - 1080p HD playback with support for videos 15-120 seconds
- **Voice Tools** - Advanced voice generation with custom tone, inflection, and patterns
- **AI Processing**
  - Background remover & changer
  - Object remover
  - Image upscaler & enhancer
  - Lip sync (photo & video)
  - AI motion transfer
  - Photo X-ray mode
  - Clothing & styling changes

### Advanced Tools
- Photo layer management
- AI Collabs Generator
- Camera Angler
- Photo Animator
- Variations (Carousel)
- Video Compressor
- Unlimited cloud storage

## 🛠️ Tech Stack

- **Frontend**: React 18 + Next.js 14
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State Management**: React Context API / Zustand
- **Icons**: Lucide React

## 📦 Installation

```bash
# Install dependencies
npm install

# Create .env.local
cp .env.example .env.local

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view in browser.
